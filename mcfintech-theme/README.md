# MC Fintech WordPress Theme

Custom WordPress theme for MC Fintech Solutions Ltd.

## Installation

1. Upload `mcfintech-theme.zip` via **WP Admin → Appearance → Themes → Add New → Upload Theme**
2. Activate the theme
3. Assign page templates in the WordPress page editor:
   - About Us → **Template: About Us**
   - Services → **Template: Services**
   - Funding → **Template: Funding**
   - Promotion → **Template: Promotion**
   - AI Videos → **Template: AI Videos**
   - My Way → **Template: My Way**
   - Aura → **Template: Aura**
   - Join Us → **Template: Join Us**
   - Contact → **Template: Contact**
   - Shop → **Template: Shop**

## Page Slugs (WordPress)

## Optional Plugins

- **Contact Form 7** — for the contact page form (the template auto-detects it)
- **WooCommerce** — for the shop page (static fallback included)
